## El negocio

El proyecto busca **organizar información de un parqueadero** para **hacer mas facil la organización de sus datos**.

## Cómo ejecutar el motor

Desde la carpeta raíz del proyecto, abre una terminal y ejecuta:

```bash
node motor.js
```
